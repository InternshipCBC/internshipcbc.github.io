Four files, one Apps Script project
  1. At script.google.com open your project (e.g. "Cohort Engine"). Keep a note of the values in your old settings first.
  2. Make the files match the four below — same names — replacing everything in each. Delete any other old files.
  3. In Code.gs fill in the SETTINGS block (Sheet ID, folder ID, token, Gemini/Groq keys, team emails). Save.
  4. Choose setup in the toolbar → Run → approve access. Read the log it prints: it carries anything in the old Applications tab across, writes the Sheet mirror, and copies the old Gmail labels onto the new ones.
  5. Deploy → Manage deployments → ✎ Edit → Version: New version → Deploy. (First time: Deploy → New deployment → Web app, Execute as Me, Anyone.)
